An AI-powered web series recommendation platform with a stunning 80s retro sci-fi neon aesthetic inspired by Stranger Things. CineVerse creates a personalized entertainment universe where AI understands your mood, taste, and viewing behavior to deliver highly relevant recommendations. Built with Next.js 14, TypeScript, TensorFlow.js, and MongoDB.

🌐 Live Website: https://cineverse-vm.vercel.app/

## ✨ Features

### 🎨 Design & Experience
- **80s Retro Sci-Fi Aesthetic**: Dark black-to-red gradient with neon glowing typography
- **Glassmorphism UI**: Premium glass cards with backdrop blur effects
- **Animated Particles**: Dynamic immersive background particle system
- **3D Portal**: Interactive Three.js portal on homepage
- **Magnetic Buttons**: Cursor-responsive button physics effects
- **Custom Cursor Glow**: Neon cursor trail for immersive interaction
- **Smooth Animations**: Framer Motion transitions throughout
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop
- **Sound Toggle**: Optional ambient audio experience

### 🤖 AI-Powered Intelligence
- **Content-Based Filtering**: Using genre & keyword similarity
- **Cosine Similarity Engine**: Vector-based recommendation algorithm
- **TensorFlow.js Integration**: Client-side machine learning processing
- **AI Series Analysis**: Instant summary & insight generation for any series
- **Personalized Recommendations**: Based on user watch history & activity
- **Mood-Based Discovery**: Get shows that match your current mood
- **Watch DNA System**: Similarity mapping across content
- **Context-Aware Suggestions**: Via AI Watch Copilot floating widget

### 🔐 User & Personalization
- **Authentication System**: Secure signup & login
- **User Profiles**: Personalized viewing space
- **Watchlist Management**: Save and organize favorites across sessions
- **Watch History Tracking**: Improves recommendation accuracy over time
- **Session Persistence**: Stay logged in securely
- **Private Dashboard**: Tailored insights, stats & suggestions

### 📺 Core Platform Features
- **Massive Series Library**: Integration with TMDB API
- **Advanced Search & Filters**: By genre, popularity, and keywords
- **Detailed Series Pages**: Complete info including cast, trailers, and ratings
- **AI Recommendations Button**: One-click AI picks on explore page
- **Similar Series Engine**: Smart deep-discovery recommendations
- **Embedded YouTube Trailers**: Watch trailers without leaving the platform
- **Real-time Content Loading**: Optimized performance & caching

## 🚀 Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **3D Graphics**: React Three Fiber, Three.js
- **Machine Learning**: TensorFlow.js
- **Database**: MongoDB Atlas
- **Authentication**: JWT-based Auth System
- **APIs**: TMDB (The Movie Database), Groq AI
- **Deployment**: Vercel
